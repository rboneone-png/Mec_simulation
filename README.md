# MecSim 結構分析

瀏覽器端的 3D 結構有限元素分析：匯入 STEP 組合件 → 設定材料與邊界條件 → 產生網格 → 線性或彈塑性求解 → 3D 檢視結果。全部在瀏覽器執行，不需後端。

## 快速開始

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # 求解器驗證（理論解比對）
npm run build    # 輸出到 dist/
```

## 功能
| 項目 | 內容 |
|---|---|
| 幾何 | STEP 匯入（occt-import-js），多檔、多實體組合件 |
| 網格 | **貼體六面體 HEX20／HEX8**（預設）：體素化後將邊界節點投影回 CAD，多面交會處保留稜線與角點，HEX20 邊中點貼合曲面；另可選 TET10 四面體（fTetWild） |
| 材料 | 42 種，分「金屬」（碳鋼／合金鋼、不鏽鋼、鋁、銅、鈦、鎂、鎳、鑄鐵）與「塑膠」（泛用、工程、玻纖強化、超級工程塑膠）；可自訂 E、ν、σy、σu、ρ；顯示應力-應變曲線、零件質量、脆性／塑膠注意事項 |
| 零件結合 | 自動偵測接觸面；每組可設為 黏合／無分離（可滑動）／無摩擦接觸（可分離）／粗糙接觸（可分離、不可滑動）／**摩擦接觸（可自訂摩擦係數 μ，附常見材料組合參考值）**／不結合 |
| 邊界條件 | 固定（可選 X/Y/Z 方向，做對稱面／滑動支承）、力向量、壓力；在 3D 視窗點選面 |
| 分析 | 線性靜力；**非線性靜力（J2 彈塑性、等向硬化）**：Newton-Raphson、負載增量、自動減步 |
| 結果顯示 | von Mises、位移、PEEQ；逐像素色帶（連續或分段等值線）、剖面（X/Y/Z 任意位置，剖切面顯示內部應力）、最大／最小值標示、網格線、高畫質模式 |
| 動態展示 | 變形動畫（往返／單向）、負載步播放、速度調整、錄製 WebM 影片 |
| 專案檔 | 儲存／開啟 `.mecsim`（含 STEP 幾何、材料、邊界條件、零件結合與設定），可自訂名稱；Ctrl+S 快速儲存 |
| PDF 報告 | 自訂名稱；含模型與材料、網格、邊界條件、零件結合、分析設定、結果摘要（安全係數／PEEQ、警告）、結果圖（應力、位移、前視圖、PEEQ）與圖表 |
| **插入／拔出模擬（3D 分頁）** | 匯入多件組合 STEP，指定插入件、方向與行程，以有限元素模擬**插入力或拔出力**：各零件獨立 TET10 網格（高精度三角化，曲面誤差 < 0.001 mm，可表現干涉量）、點對面大滑移接觸（雙向搜尋、罰函數）＋庫倫摩擦（含摩擦／法向耦合的非對稱切線，BiCGSTAB 求解）、可選彈塑性；右側 3D 顯示 von Mises、位移、**接觸壓力**，可逐行程播放動畫；輸出插入（拔出）力-行程曲線、最大力、接觸法向力；CAD 可為插入完成位置或起點；推動面／固定面可自訂或自動判斷 |
| **解析估算（分頁）** | **壓入配合**（軸／孔干涉配合：Lamé 厚壁圓筒＋導角楔形摩擦，求插入力-行程曲線、拔出力、傳遞扭矩、接觸壓力與應力）與**懸臂卡扣**（插入力、退出力、根部應變）；可設摩擦係數 μ（金屬／塑膠參考值）；可選「依應力-應變曲線」（降伏後割線模數／彎矩-曲率積分）或線彈性，並以虛線對照；可存入專案、輸出 PDF |
| 其他 | 負載-位移曲線、安全係數、CSV／PNG 匯出 |

## 求解方法
- 單位：mm、N、MPa
- 3×3 區塊 CSR 稀疏矩陣、IC(0) 前置條件共軛梯度法，於 Web Worker 執行
- HEX20 採 2×2×2 縮減積分（同 C3D20R）；彈塑性採熱啟動與非精確 Newton 加速
- 彈塑性：徑向回歸 + 一致切線矩陣；硬化曲線由材料的工程應力-應變曲線轉換為真應力-塑性應變
- 多件組合：網格在接觸面共用節點（黏合）；非黏合介面於求解時拆開節點，以罰函數彈簧連接
- 接觸：法向僅受壓（主動集合 Newton 迭代，狀態震盪時凍結），切向依類型決定可否滑動；摩擦接觸採庫倫摩擦（罰函數＋回歸映射，|ft| ≤ μ·fn 黏著、超過滑動，滑移量跨負載步保留）；以微小穩定化彈簧防止剛體模態，若其承受超過 1% 負載會警告「形成機構」
- 應力：積分點外插到節點後平均

## 部署到 GitHub Pages
1. 將程式合併到 `main`
2. GitHub repo → Settings → Pages → Source 選 **GitHub Actions**
3. 之後每次 push 到 `main`，`.github/workflows/deploy.yml` 會自動測試、建置並部署


## 限制
- 3D 插入模擬：小應變（移動件為剛體平移＋小變形），大轉角的卡扣臂結果偏保守；網格過粗時插入力曲線會有階梯起伏；示範例中軸套底面全固定，中段接觸壓力比 Lamé 平面應力解高約 25–40%（端部拘束與 3D 效應）
- 小應變、小變形；不含幾何非線性、動態分析
- 結構模擬的零件結合：接觸面須在網格中相接（共用面），不含大滑移（大滑移請用插入模擬分頁）；摩擦採靜摩擦＝動摩擦的庫倫模型
- 尖角、固定邊緣的應力為奇異點，數值會隨網格加密而上升，請以遠離奇異點處或收斂趨勢判讀
- 理想塑性材料超過極限負載時會停止於最後收斂步
