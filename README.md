# MecSim 應力應變模擬

瀏覽器端的線彈性結構分析工具：匯入 STEP 組合件 → 設定材料與邊界條件 → 求解 → 3D 檢視應力與變形。

## 快速開始

```bash
npm install
npm run dev      # 開發伺服器 http://localhost:5173
npm run build    # 輸出到 dist/，可部署到任何靜態主機
npm test         # 懸臂樑理論解驗證
```

## 功能
- **STEP 匯入**（OpenCascade WASM，occt-import-js），支援多檔、多實體組合件
- **多零件**：每件各自指定材料；相接觸的零件以黏合（bonded）方式一起計算
- **邊界條件**：固定約束、力（向量）、壓力；在 3D 視窗直接點選面
- **材料庫**：鋼、不鏽鋼、鋁、鈦、銅、ABS，可自訂 E、ν、σy、σu，並顯示應力-應變曲線
- **結果**：von Mises 應力、位移（總量／分量）、變形放大、各零件安全係數、CSV／PNG 匯出

## 求解方法
- 單位：mm、N、MPa
- 將零件體素化成 8 節點六面體元素，以 Jacobi 預條件共軛梯度法（矩陣自由）於 Web Worker 求解
- 應力於元素角點計算後在節點平均
- 驗證：懸臂樑（`test/cantilever.test.mjs`）撓度誤差 < 1%、根部應力誤差 < 1%（解析度 80）

## 限制（目前版本）
- 線彈性、小變形；不含塑性、接觸分離、摩擦
- 體素網格在斜面／曲面為階梯狀，邊角或固定邊緣可能出現應力集中（奇異點）；請以提高解析度觀察收斂
- 比網格尺寸 h 還薄的特徵不會被網格化

`samples/bracket_shaft.step` 是可用來試用的範例組合件。
